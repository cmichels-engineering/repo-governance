# Security Policy

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue.

Please report privately through GitHub Security Advisories for this repository.
Include:

- reproduction steps
- impacted resources
- severity assessment
- suggested mitigation (if available)

## Scope

Security-sensitive areas include:

- GitHub governance policy drift that weakens protections
- unsafe or over-privileged automation patterns
- accidental exposure of credentials or private values in IaC inputs

## Response Targets

- triage within 3 business days
- prioritize confirmed issues and publish mitigations after validation
